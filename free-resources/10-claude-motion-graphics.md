# [이현 무료자료 10] 클로드에게 모션그래픽 학습시키기

퍼스널 브랜딩 빌더 | 이현

> 💡 **애프터이펙트 몰라도 됩니다.** 클로드는 영상을 '코드'로 만들 수 있어요.
> 공식 모션 스킬 + 내 스타일 파일 하나만 넣어두면, 말 한 줄로 **릴스용 모션그래픽 MP4** 가 나옵니다.
> 쓰면 쓸수록 내 취향을 기억해서 점점 내 스타일로 만들어줘요.

## 📌 준비물

- **클로드 데스크톱 앱** + 유료 플랜(Pro 이상) 👉 https://claude.com/download
- 앱 위쪽 **Code** 탭 (Claude Code)
- **Node.js** — 없으면 STEP 1에서 클로드가 같이 설치해줘요

> 🤔 **왜 '코드'로 만들어요?**
> 클로드는 영상을 직접 그리진 못하지만, **Remotion**(리액트로 영상을 만드는 도구)으로 코드를 짜면
> 그 코드가 그대로 MP4 영상이 돼요. 그래서 글자 위치·속도·색을 **숫자로 정확하게** 고칠 수 있어요.

## 🔧 STEP 1. 설치 — 붙여넣기 한 번

**1.** 컴퓨터에 빈 폴더 하나 만들기 (예: `모션그래픽`)

**2.** 클로드 앱 **Code** 탭 → 방금 만든 폴더 선택

**3.** 아래 그대로 붙여넣기

```
이 폴더에 Remotion 영상 프로젝트를 만들어줘.
1. Node.js 가 없으면 설치 방법부터 알려줘.
2. 빈 Remotion 프로젝트를 만들고 npm install 까지 해줘.
3. 공식 Remotion 스킬을 설치해줘: npx skills add remotion-dev/skills
4. 끝나면 npx remotion studio 로 미리보기가 열리는지 확인해줘.
```

중간에 허용할지 물어보면 **허용** 누르면 돼요.

✅ 브라우저에 Remotion Studio(영상 미리보기 화면)가 뜨면 성공!

> 공식 스킬(`remotion-best-practices`)은 클로드에게 **Remotion 문법**을 가르쳐줘요.
> 하지만 "릴스에서 뭐가 좋은 모션인지"는 모르기 때문에 STEP 2가 필요합니다.

## 🧠 STEP 3. 내 스타일 학습시키기 (제일 중요!)

클로드는 대화가 끝나면 기억을 잃어요. 그래서 **파일에 적어두는 것 = 학습**입니다.
클로드는 모션을 만들 때마다 `motion-style.md` 를 먼저 읽어요.

### 방법 A — 말로 알려주기

```
motion-style.example.md 를 복사해서 프로젝트 루트에 motion-style.md 를 만들어줘.
내 정보는 이거야:
- 강조색: [예: 형광 노랑 #E8FF3A]
- 배경: [예: 거의 검정]
- 폰트: [예: Pretendard]
- 분위기: [예: 빠르고 깔끔하게, 정보형 릴스]
- 내 인스타 핸들: @[아이디]
궁금한 건 나한테 물어봐줘.
```

### 방법 B — 레퍼런스 영상으로 알려주기 (추천)

마음에 드는 릴스 화면을 **캡처 3~5장** 찍어서 대화창에 끌어다 놓고:

```
이 캡처들은 내가 따라하고 싶은 모션그래픽 스타일이야.
색, 폰트 굵기, 글자 크기, 강조 방식, 화면 배치를 분석해서
motion-style.md 에 '참고 레퍼런스' 와 '분위기' 로 정리해줘.
그다음 이 스타일로 KineticHook 을 다시 렌더해서 비교해줘.
```

> 💡 영상 링크만 주면 클로드가 못 볼 수 있어요. **캡처 이미지**가 가장 확실해요.

## 📺 STEP 3+. 채널별로 스타일 나눠 쓰기 (인스타 · 쇼츠 · 롱폼 · 영어 앱)

> 💡 **색·폰트·핸들은 셋 다 똑같이**, 나머지만 채널에 맞게 바꿔요. 어디서 봐도 "그 사람 영상"으로 알아보게 하려고요.

| | 개인 인스타 (릴스) | 유튜브 쇼츠 | 유튜브 롱폼 |
| --- | --- | --- | --- |
| 크기 | 1080×1920 | 1080×1920 | 1920×1080 |
| 목표 | **저장·공유** | **넘기지 않게 + 반복 재생** | **이해를 돕는 장치** |
| 속도 | 중간 (장면 2~3초) | 가장 빠름 (1~2초) | 차분 (3~6초) |
| 글자 | 크게 | 가장 크게 | 정보 밀도 ↑ |
| 피해야 할 곳 | 오른쪽 버튼, 아래 캡션 | 오른쪽 버튼 열, 아래 제목 영역 | 하단 자막, 엔드스크린 자리 |
| 연출 강도 | 중간 | 높음 (슬램·글리치 OK) | 차분 (플래시 X) |
| 특별 장치 | 그리드 3:4 썸네일 고려 | **끝→처음 루프** | **챕터 카드, 하단 자막바** |

스킬 안에 채널별 스타일 파일(`styles/instagram.md`, `styles/youtube-shorts.md`, `styles/youtube-long.md`)이 있어서, **어디에 올릴지만 말하면** 크기·속도·글자 크기가 자동으로 바뀌어요.

```
[유튜브 쇼츠]용으로 만들어줘. 주제: [ ]
```
```
이 내용을 인스타 릴스, 유튜브 쇼츠, 유튜브 롱폼 챕터 카드 3가지 버전으로 렌더해줘.
```
```
롱폼 영상에 쓸 챕터 카드 5개 만들어줘. 챕터 제목: [1. ○○ / 2. ○○ / ...]
하단 자막바도 "[이름] / [소개 한 줄]" 로 투명 배경 렌더해줘.
```

> 🧠 피드백도 채널별로 기억해요. "쇼츠는 더 빠르게" → 쇼츠 파일에만, "강조색 노랑으로" → 세 채널 공통에 저장돼요.

## ⚡ STEP 4. 복붙 명령어 6개

> 공통 팁: 클로드는 먼저 **장면 표(스토리보드)** 를 보여줘요. 표를 보고 OK 해야 코드를 짭니다.
> 한 번에 길게 시키지 말고 **3~6초짜리 조각**으로 만드는 게 퀄리티가 좋아요.

### 1. 훅 인트로

```
reels-motion-graphics 스킬로 훅 인트로 만들어줘.
문장: "[예: 퇴근 후 30분으로 / 팔로워 1만 / 만든 방법]"
강조 단어: [예: 1만]
길이 3초
```

### 2. 숫자 카운트업

```
"[예: 매출 0원 → 3,200만원]" 숫자가 올라가는 모션 만들어줘.
숫자는 1초 동안 카운트업, 마지막에 살짝 튕기게. 길이 3초.
```

### 3. 리스트 ("○가지 방법")

```
"[예: 릴스 조회수 올리는 3가지]" 리스트 모션 만들어줘.
항목: ① [ ] ② [ ] ③ [ ]
항목당 2초, 지나간 항목은 흐리게 남겨줘.
```

### 4. 단어 강조 자막

```
이 대본으로 단어 단위 강조 자막 만들어줘.
지금 말하는 단어만 강조색으로 커지게. 화면 아래쪽 안전영역 안에.
대본: [붙여넣기]
```

### 5. 비포 / 애프터

```
비포/애프터 모션 만들어줘. 9:16 이라 위아래로 나눠서.
비포: [예: 팔로워 312명] → 애프터: [예: 팔로워 1.2만]
가운데 선이 쓸고 지나가며 바뀌게. 길이 4초.
```

### 6. 엔딩 CTA

```
엔딩 모션 만들어줘.
내 핸들 @[아이디] 등장 → "[예: 저장해두고 따라하세요]" 한 줄 → 마지막 1초 정지.
```

✅ 만든 조각들은 캡컷·VLLO 같은 편집 앱에서 내 영상 위/사이에 얹으면 끝!

> 💡 **배경 투명 영상**이 필요하면 → `"배경 투명하게 ProRes 4444 .mov 로 렌더해줘"` 라고 하면 촬영 영상 위에 바로 얹을 수 있어요.

## 🎨 STEP 4+. 효과 라이브러리 6종 — 한 단계 위 퀄리티

> 💡 기본 모션만으로 밋밋할 때, 무료 오픈소스 라이브러리를 붙이면 **애프터이펙트 같은 효과**가 나와요.
> 단, 그냥 붙이면 렌더할 때마다 결과가 달라지거나 화면이 깨져요. 그래서 스킬에 **테스트 통과한 템플릿 + 주의사항**을 같이 넣어뒀어요.

| 라이브러리 | 이런 효과 | 이렇게 말하면 돼요 |
| --- | --- | --- |
| **Matter.js** | 단어 카드가 툭툭 떨어져 쌓임 (물리) | "떨어져서 쌓이는" |
| **Rough.js** | 손으로 그린 듯한 박스·화살표·빗금 | "손그림 다이어그램" |
| **PixiJS + filters** | 글리치, 네온 글로우, 볼록 왜곡, ASCII | "글리치 / 글로우" |
| **Anime.js** | 글자 하나씩 + 선 그려짐 + 태그 팝업을 한 박자로 | "순서대로 착착" |
| **p5.brush** | 형광펜 밑줄, 연필 체크, 수채화 얼룩 | "형광펜 / 수채화" |
| **thinking-orbs** | AI가 생각하는 듯한 점 구체 (검색·풀이·작성 9가지) | "AI 생각 중" |

### 처음 한 번 — 설치

```
reels-motion-graphics 스킬의 references/libraries.md 를 읽고,
템플릿 6개(PhysicsWords, SketchDiagram, PixiGlitch, AnimeTimeline, BrushHighlight, ThinkingOrbs)에
필요한 라이브러리를 설치해서 Root.tsx 에 전부 등록해줘.
각각 대표 프레임 1장씩 still 로 뽑아서 보여줘.
```

### 복붙 명령어

**① 물리 — 문제점 나열 릴스**
```
PhysicsWords 템플릿으로 만들어줘.
제목: "[예: 다이어트 실패하는 이유]"
카드: [예: 야식, 수면 부족, 물 안 마심, 운동만 함, 기록 안 함]
마지막 카드만 강조색. 길이 4초.
```

**② 손그림 — 과정/순서 설명**
```
SketchDiagram 템플릿으로 [예: 기획 → 촬영 → 편집 → 업로드] 다이어그램 만들어줘.
선이 살짝 보글보글 떨리게(boil), 마지막 단계만 빗금 채우기.
```

**③ 글리치 — 충격 훅**
```
PixiGlitch 템플릿으로 "[예: 이거 모르면 손해]" 글리치 인트로 만들어줘.
처음 0.3초 강하게 지지직 → 잠잠 → 1.5초에 한 번 더 툭. 글로우 살짝.
```

**④ 안무 — 정보형 타이틀 카드**
```
AnimeTimeline 템플릿으로 만들어줘.
작은 글씨: "[예: 직장인 부업]" / 제목: "[예: 월 50 버는 루틴]" / 태그: [예: 퇴근 후, 주말 2시간, 노트북 1대]
글자는 하나씩 튀어오르고, 밑줄은 손글씨처럼 그려지게.
```

**⑤ 붓 — 저장 유도 강조**
```
BrushHighlight 템플릿으로 "[예: 저장해두면 / 평생 써먹는 문장]" 만들어줘.
두 번째 줄에 형광펜 밑줄, 옆에 연필 체크, 뒤에 수채화 얼룩.
```

**⑥ AI 생각 중 — "AI한테 시켰더니" 콘텐츠**
```
ThinkingOrbs 템플릿으로 만들어줘.
상태 순서: [예: searching "경쟁사 분석 중" → solving "전략 짜는 중" → composing "카피 쓰는 중"]
상태당 1.3초. 점 색은 내 강조색으로.
```

> 🚨 **한 영상에 효과는 1~2개만!** 글리치+수채화+물리 다 섞으면 오히려 싸 보여요.

## 🔥 STEP 4++. 바이럴 영상 프롬프트 공식

> 💡 Claude로 만든 **바이럴 모션 영상 362개의 실제 프롬프트**를 분석해서 공통점만 뽑았어요.
> (출처: [awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos) — 원본 영상과 프롬프트 전체는 여기서 볼 수 있어요)

### 터진 프롬프트의 공통점 6가지

| 공통점 | 예시 표현 |
| --- | --- |
| **① 숫자로 스펙** | "15초, 1080x1920, 30fps, MP4로 렌더" |
| **② 기준을 확 올리기** | "네가 얼마나 대단한 모션 디자이너인지 보여주는 **쇼릴**처럼. 아끼지 말고 다 써." |
| **③ 비트에 맞춰 컷** | "120BPM, **모든 전환은 비트에** 맞춰" |
| **④ 브랜드 규칙** | "색 3개만, **한 장면에 한 메시지**, 핵심은 가운데, 여백 넉넉히" |
| **⑤ 진짜 데이터만** | "내가 준 숫자·문구만 써. **지어내지 마.**" |
| **⑥ 검수 후 렌더** | "장면마다 1장씩 캡처해서 먼저 확인하고, 잘림·겹침 고친 다음 렌더해" |

> 📊 재밌는 점: 362개 중 **세로(9:16) 영상은 63개뿐**이에요. 대부분 가로 영상이라, 릴스·쇼츠용 세로 모션은 아직 경쟁이 적어요.

### 복붙 템플릿 — 빈칸만 채우세요

```
reels-motion-graphics 스킬로 만들어줘.

<결과물>
[15]초, 1080x1920(9:16), 30fps MP4.
장면마다 1장씩 캡처해서 먼저 보여주고, 잘림·겹침 고친 다음 렌더해줘.
</결과물>

<내용>
주제: [예: 직장인이 퇴근 후 1시간으로 부업 시작하는 법]
첫 1초 훅 문장: [예: 월급 말고 통장에 꽂히는 돈]
장면 순서: [문제 → 해결 → 3단계 방법 → 증거 1개 → 내 핸들]
숫자/사실: [예: 3개월, 첫 수익 37만원]  ← 이것만 쓰고 지어내지 마
</내용>

<스타일>
motion-style.md 따르기. 색 3개만, 한 장면에 한 메시지, 여백 넉넉히.
[120]BPM 기준으로 모든 전환은 비트에 맞춰.
효과: [예: 형광펜 강조 / 없음]
</스타일>

모르는 건 시작할 때 한 번에 물어보고, 그다음엔 끝까지 만들어줘.
```

```
나를 소개하는 15초 9:16 모션그래픽 쇼릴을 만들어줘.
세계 최고 모션 디자이너의 쇼릴처럼, 아끼지 말고 다 써.

마지막 프레임이 첫 프레임과 같아서 무한 반복되게.
```

**② 정보형 5장면 (30초)**

```
30초 9:16 설명 릴스. 5장면:
1 사람들이 겪는 문제 → 2 내가 하는 일 → 3 방법 3단계 → 4 증거 1개 → 5 내 핸들.
굵은 글씨, 부드러운 전환, 내 브랜드 색.
내 내용: [무엇을, 누구에게, 증거 숫자]
```

**③ 과정 보여주기 (레시피형)**
```
"[예: 빈 노션 페이지 → 완성된 주간 플래너]" 가 만들어지는 과정을 20초 9:16 모션으로.
각 단계가 들어갈 때 이름과 핵심 수치가 같이 뜨게.
처음은 텅 빈 화면, 끝은 완성본이 꽉 찬 화면.
```

### 🎵 BGM까지 코드로 — "사소한 질문 × 과한 연출"

> 💡 일본에서 화제였던 사례: **"오늘 무슨 요일이지? BGM 넣은 30초 멋진 모션그래픽으로 알려줘 (전력으로)"**
> → 질문은 시시한데 답이 영화 예고편급이라 웃긴 거예요. BGM도 외부 음원 없이 **코드로 즉석 합성**했어요.

스킬에 BGM 합성 도구(`tools/synth_bgm.py`)를 넣어뒀어요. 저작권 걱정 없는 BGM을 만들고, **비트 위치까지 계산**해서 컷이 음악에 딱딱 맞아요.

```
오늘 무슨 요일이지? BGM 넣은 12초 멋진 모션그래픽으로 알려줘. 전력으로.
BeatDayAnswer 템플릿이랑 synth_bgm.py 써서, 드롭 순간에 요일이 쾅 나오게.
오늘 날짜는 [예: 2026-11-16].
```

**같은 공식으로 바꿔 쓰기**
- "지금 몇 시야?" / "점심 뭐 먹지?" / "월급날까지 며칠 남았어?"
- 내 분야 버전: "오늘 팔로워 몇 명 늘었어? [숫자]" → 숫자 공개를 드롭에

### 😂 패러디 런칭 영상

> 진지한 SaaS 런칭 영상 문법에 농담을 넣으면 밈이 돼요. (예: "LinkedIn이 싫어서 만든 런칭 영상")

```
진짜 스타트업 런칭 영상처럼 아주 진지하고 고급스럽게, 근데 내용은 패러디로 15초 9:16 영상 만들어줘.
제품: "[예: 퇴사 버튼 — 누르면 월요일이 사라집니다]"
기능 3개: [예: 월요일 삭제, 회의 자동 거절, 칼퇴 알림]
마지막은 로고 + "[예: Coming never]". BGM 합성해서 비트에 맞춰.
```

> 💡 **프롬프트는 두 문장이어도 돼요.** 대신 **① 무엇을 ② 어떤 기준으로(전력으로, 쇼릴처럼)** 이 두 가지는 꼭 넣으세요.

### 🎬 레퍼런스 영상 하나로 따라 만들기 (가장 강력)

> 💡 "레퍼런스 영상 하나 줬더니 시네마틱 런칭 영상이 나왔다" — 요즘 제일 많이 보이는 사례예요.
> 클로드는 영상을 **볼 수도, 소리를 들을 수도 없어요.** 그래서 스킬에 **영상 분석 도구**를 넣어뒀어요.
> 장면마다 캡처를 뽑아 한 장으로 붙이고, 음악 파형을 숫자로 분석해서 **BPM·비트·드롭 위치**를 찾아요.

**1.** 프로젝트 폴더에 레퍼런스 영상(mp4)을 넣고 (내 영상이거나 참고용으로만 쓰세요)

**2.** 붙여넣기 👇
```
reference.mp4 를 analyze_reference.py 로 분석해서
장면별 캡처 시트랑 리듬(BPM, 컷 길이, 컷이 비트에 맞는지)을 정리해줘.
그 스타일과 리듬으로, 내용은 [예: 내 온라인 강의 런칭]으로 15초 9:16 영상 만들어줘.
로고·문구·캐릭터는 베끼지 말고 스타일과 리듬만 가져와.
BGM과 효과음도 합성해서 움직임이 착지하는 순간에 맞춰줘.
```

> 🎵 **내 음악을 쓰고 싶으면** 음원 파일을 넣고 `"이 음악 분석해서 비트에 컷 맞춰줘"` 하면 돼요.

### 📊 정치·경제 전망치 그래프 영상

> 💡 "$3,000 견적 받은 영상을 프롬프트 한 번에" 사례의 구조화 프롬프트를 **전망치 그래프용**으로 바꿔 넣었어요.
> 전망 영상은 신뢰가 생명이라 규칙을 더했어요: **실적은 실선, 전망은 점선 + 범위 / 기관·발표 시점·기준일·출처 필수 / 정치 해석은 중립 / 숫자 지어내기 금지.**

```
ForecastChart 템플릿으로 유튜브 롱폼용 15초 전망 그래프 만들어줘.
주제: [예: 2027년 경제성장률 전망]
실적: [연도: 값 …] (출처: [ ])
전망: [기관 A, 발표 연월, 값, 범위] / [기관 B, 발표 연월, 값]
기준: [2026년 10월 기준], 단위 [%], 손글씨 메모: [데이터가 말하는 한 줄]
BGM·효과음 합성, -14 LUFS로 맞추고 측정값 알려줘.
```
전체 템플릿(빈칸 채우기 버전)은 스킬 폴더의 `references/forecast-film-prompt.md` 에 있어요.

### 🐰 내 캐릭터로 숏폼 (인스타용)

> 💡 일본 사례: 예전에 만든 캐릭터 그림 + ElevenLabs 연결 → 클로드가 "나레이션 만들게요", "효과음도 만들까요?" 하며 알아서 만들어줬대요.

```
public/character 폴더의 내 캐릭터로 인스타 릴스 20초 만들어줘.
캐릭터 말투: [예: ~오파스]. 대사는 큰 자막으로.
음성 연결이 없으면 효과음 + 자막만으로 만들어줘.
```
> 🚨 캐릭터는 **내가 만든 것만**. 유명 캐릭터·남의 그림은 쓰지 마세요.

### 📚 영어 앱: 아이들 학습 게임 · 그림책 장면

> 💡 "영상 생성 AI가 아니라 **코드**로 만들어서, 그림·소리·애니메이션을 세밀하게 제어하고 **매번 똑같이** 나온다" — 교재에 딱 맞는 이유예요.
> 스킬에 4번째 스타일 **어린이 영어 앱**(앱 브랜드 색, 둥근 글씨, 느린 리듬)과 `ReadAlong` 템플릿을 넣었어요.

**ReadAlong 이 하는 일:** 그림책 문장을 읽는 단어마다 하이라이트 → 그 단어의 그림이 통통 반응 → 핵심 단어 파닉스(c · a · t → cat) → 그림 고르기 퀴즈

```
kids-english 스타일로 ReadAlong 만들어줘.
문장: "[예: The little cat plays with a red ball under the big sun.]"
그림과 연결할 단어: [cat, ball, sun]
파닉스 단어: [cat = c · a · t]
퀴즈: "[Which one is the cat?]" 보기 [fish, cat, tree]
TTS가 연결돼 있으면 내레이션 넣고 단어 시각에 맞춰줘. 없으면 자막만.
```
> ⏱️ 작업이 길어서 중간에 끊기면 **"계속"** 한 마디만 보내세요. 처음부터 다시 시킬 필요 없어요.

결과물이 마음에 안 들면 **구체적으로** 말하고, 마지막에 이 한 줄을 붙이세요.

```
[예: 등장이 너무 느려. 반으로 줄이고, 강조 박스 대신 밑줄로 바꿔줘.]

```

이렇게 5~10번만 반복하면 `배운 것` 목록이 쌓여서, **처음부터 내 스타일로** 나오기 시작해요.
