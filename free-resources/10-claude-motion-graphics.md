# [이현 무료자료 10] 클로드에게 모션그래픽 학습시키기

퍼스널 브랜딩 빌더 | 이현

> 💡 **애프터이펙트 몰라도 됩니다.** 클로드는 영상을 '코드'로 만들 수 있어요.
> 공식 모션 스킬 + 내 스타일 파일 하나만 넣어두면, 말 한 줄로 **릴스용 모션그래픽 MP4** 가 나옵니다.
> 쓰면 쓸수록 내 취향을 기억해서 점점 내 스타일로 만들어줘요.

---

## 👀 한눈에 보기

| STEP | 할 일 | 걸리는 시간 |
| --- | --- | --- |
| **STEP 1** | 영상 만드는 도구(Remotion) + 공식 스킬 설치 | 5분 |
| **STEP 2** | 릴스 전용 스킬 넣기 (안전영역·속도 규칙) | 1분 |
| **STEP 3** | 내 스타일 알려주기 = **학습** | 3분 |
| **STEP 4** | 복붙 명령어로 만들기 | 1개당 3~5분 |
| **STEP 5** | 피드백 → 클로드가 기억 | 계속 |

## 📌 준비물

- **클로드 데스크톱 앱** + 유료 플랜(Pro 이상) 👉 https://claude.com/download
- 앱 위쪽 **Code** 탭 (Claude Code)
- **Node.js** — 없으면 STEP 1에서 클로드가 같이 설치해줘요

> 🤔 **왜 '코드'로 만들어요?**
> 클로드는 영상을 직접 그리진 못하지만, **Remotion**(리액트로 영상을 만드는 도구)으로 코드를 짜면
> 그 코드가 그대로 MP4 영상이 돼요. 그래서 글자 위치·속도·색을 **숫자로 정확하게** 고칠 수 있어요.

---

## 🔧 STEP 1. 설치 — 붙여넣기 한 번

**1.** 컴퓨터에 빈 폴더 하나 만들기 (예: `모션그래픽`)

**2.** 클로드 앱 **Code** 탭 → 방금 만든 폴더 선택

**3.** 아래 그대로 붙여넣기

```
이 폴더에 Remotion 영상 프로젝트를 만들어줘.
1. Node.js 가 없으면 설치 방법부터 알려줘.
2. 빈 Remotion 프로젝트를 만들고 npm install 까지 해줘.
3. 공식 Remotion 스킬을 설치해줘: npx skills add remotion-dev/skills
4. 끝나면 npx remotion studio 로 미리보기가 열리는지 확인해줘.
```

중간에 허용할지 물어보면 **허용** 누르면 돼요.

✅ 브라우저에 Remotion Studio(영상 미리보기 화면)가 뜨면 성공!

> 공식 스킬(`remotion-best-practices`)은 클로드에게 **Remotion 문법**을 가르쳐줘요.
> 하지만 "릴스에서 뭐가 좋은 모션인지"는 모르기 때문에 STEP 2가 필요합니다.

## 🎬 STEP 2. 릴스 전용 스킬 넣기

이 자료 폴더의 [`skills/reels-motion-graphics`](../skills/reels-motion-graphics/) 가 그 스킬이에요. 안에 들어 있는 것:

| 파일 | 역할 |
| --- | --- |
| `SKILL.md` | 릴스 규칙 — 9:16 안전영역, 한 화면 3줄, 0.5초 안에 읽히는 훅, 등장/퇴장 속도, 이징 |
| `motion-style.example.md` | 내 브랜드 색·폰트·분위기를 적는 양식 |
| `templates/KineticHook.tsx` | 바로 쓰는 훅 문장 애니메이션 (테스트 렌더 완료) |
| `templates/` 나머지 5개 | 물리·손그림·글리치·안무·붓 효과 템플릿 (아래 STEP 4+ 참고) |
| `references/libraries.md` | 효과 라이브러리 쓸 때 클로드가 꼭 지켜야 할 규칙 |

아래 붙여넣기 👇

```
https://github.com/zzzro21/zzzro 의 skills/reels-motion-graphics 폴더를
이 프로젝트의 .claude/skills/reels-motion-graphics 로 복사해줘.
그리고 templates/KineticHook.tsx 를 src 에 넣고 Root.tsx 에 등록해서
1080x1920, 30fps, 3초짜리로 렌더해봐.
```

✅ `out` 폴더에 MP4가 생기고, 검은 화면에 문장 3줄이 튀어오르며 **'1만'** 에 빨간 박스가 채워지면 성공!

> 💡 스킬을 넣은 뒤에는 **새 대화**를 열어야 스킬이 인식돼요.

## 🧠 STEP 3. 내 스타일 학습시키기 (제일 중요!)

클로드는 대화가 끝나면 기억을 잃어요. 그래서 **파일에 적어두는 것 = 학습**입니다.
클로드는 모션을 만들 때마다 `motion-style.md` 를 먼저 읽어요.

### 방법 A — 말로 알려주기

```
motion-style.example.md 를 복사해서 프로젝트 루트에 motion-style.md 를 만들어줘.
내 정보는 이거야:
- 강조색: [예: 형광 노랑 #E8FF3A]
- 배경: [예: 거의 검정]
- 폰트: [예: Pretendard]
- 분위기: [예: 빠르고 깔끔하게, 정보형 릴스]
- 내 인스타 핸들: @[아이디]
궁금한 건 나한테 물어봐줘.
```

### 방법 B — 레퍼런스 영상으로 알려주기 (추천)

마음에 드는 릴스 화면을 **캡처 3~5장** 찍어서 대화창에 끌어다 놓고:

```
이 캡처들은 내가 따라하고 싶은 모션그래픽 스타일이야.
색, 폰트 굵기, 글자 크기, 강조 방식, 화면 배치를 분석해서
motion-style.md 에 '참고 레퍼런스' 와 '분위기' 로 정리해줘.
그다음 이 스타일로 KineticHook 을 다시 렌더해서 비교해줘.
```

> 💡 영상 링크만 주면 클로드가 못 볼 수 있어요. **캡처 이미지**가 가장 확실해요.

## ⚡ STEP 4. 복붙 명령어 6개

> 공통 팁: 클로드는 먼저 **장면 표(스토리보드)** 를 보여줘요. 표를 보고 OK 해야 코드를 짭니다.
> 한 번에 길게 시키지 말고 **3~6초짜리 조각**으로 만드는 게 퀄리티가 좋아요.

### 1. 훅 인트로

```
reels-motion-graphics 스킬로 훅 인트로 만들어줘.
문장: "[예: 퇴근 후 30분으로 / 팔로워 1만 / 만든 방법]"
강조 단어: [예: 1만]
길이 3초
```

### 2. 숫자 카운트업

```
"[예: 매출 0원 → 3,200만원]" 숫자가 올라가는 모션 만들어줘.
숫자는 1초 동안 카운트업, 마지막에 살짝 튕기게. 길이 3초.
```

### 3. 리스트 ("○가지 방법")

```
"[예: 릴스 조회수 올리는 3가지]" 리스트 모션 만들어줘.
항목: ① [ ] ② [ ] ③ [ ]
항목당 2초, 지나간 항목은 흐리게 남겨줘.
```

### 4. 단어 강조 자막

```
이 대본으로 단어 단위 강조 자막 만들어줘.
지금 말하는 단어만 강조색으로 커지게. 화면 아래쪽 안전영역 안에.
대본: [붙여넣기]
```

### 5. 비포 / 애프터

```
비포/애프터 모션 만들어줘. 9:16 이라 위아래로 나눠서.
비포: [예: 팔로워 312명] → 애프터: [예: 팔로워 1.2만]
가운데 선이 쓸고 지나가며 바뀌게. 길이 4초.
```

### 6. 엔딩 CTA

```
엔딩 모션 만들어줘.
내 핸들 @[아이디] 등장 → "[예: 저장해두고 따라하세요]" 한 줄 → 마지막 1초 정지.
```

✅ 만든 조각들은 캡컷·VLLO 같은 편집 앱에서 내 영상 위/사이에 얹으면 끝!

> 💡 **배경 투명 영상**이 필요하면 → `"배경 투명하게 ProRes 4444 .mov 로 렌더해줘"` 라고 하면 촬영 영상 위에 바로 얹을 수 있어요.

## 🎨 STEP 4+. 효과 라이브러리 5종 — 한 단계 위 퀄리티

> 💡 기본 모션만으로 밋밋할 때, 무료 오픈소스 라이브러리를 붙이면 **애프터이펙트 같은 효과**가 나와요.
> 단, 그냥 붙이면 렌더할 때마다 결과가 달라지거나 화면이 깨져요. 그래서 스킬에 **테스트 통과한 템플릿 + 주의사항**을 같이 넣어뒀어요.

| 라이브러리 | 이런 효과 | 이렇게 말하면 돼요 |
| --- | --- | --- |
| **Matter.js** | 단어 카드가 툭툭 떨어져 쌓임 (물리) | "떨어져서 쌓이는" |
| **Rough.js** | 손으로 그린 듯한 박스·화살표·빗금 | "손그림 다이어그램" |
| **PixiJS + filters** | 글리치, 네온 글로우, 볼록 왜곡, ASCII | "글리치 / 글로우" |
| **Anime.js** | 글자 하나씩 + 선 그려짐 + 태그 팝업을 한 박자로 | "순서대로 착착" |
| **p5.brush** | 형광펜 밑줄, 연필 체크, 수채화 얼룩 | "형광펜 / 수채화" |

### 처음 한 번 — 설치

```
reels-motion-graphics 스킬의 references/libraries.md 를 읽고,
템플릿 5개(PhysicsWords, SketchDiagram, PixiGlitch, AnimeTimeline, BrushHighlight)에
필요한 라이브러리를 설치해서 Root.tsx 에 전부 등록해줘.
각각 대표 프레임 1장씩 still 로 뽑아서 보여줘.
```

### 복붙 명령어

**① 물리 — 문제점 나열 릴스**
```
PhysicsWords 템플릿으로 만들어줘.
제목: "[예: 다이어트 실패하는 이유]"
카드: [예: 야식, 수면 부족, 물 안 마심, 운동만 함, 기록 안 함]
마지막 카드만 강조색. 길이 4초.
```

**② 손그림 — 과정/순서 설명**
```
SketchDiagram 템플릿으로 [예: 기획 → 촬영 → 편집 → 업로드] 다이어그램 만들어줘.
선이 살짝 보글보글 떨리게(boil), 마지막 단계만 빗금 채우기.
```

**③ 글리치 — 충격 훅**
```
PixiGlitch 템플릿으로 "[예: 이거 모르면 손해]" 글리치 인트로 만들어줘.
처음 0.3초 강하게 지지직 → 잠잠 → 1.5초에 한 번 더 툭. 글로우 살짝.
```

**④ 안무 — 정보형 타이틀 카드**
```
AnimeTimeline 템플릿으로 만들어줘.
작은 글씨: "[예: 직장인 부업]" / 제목: "[예: 월 50 버는 루틴]" / 태그: [예: 퇴근 후, 주말 2시간, 노트북 1대]
글자는 하나씩 튀어오르고, 밑줄은 손글씨처럼 그려지게.
```

**⑤ 붓 — 저장 유도 강조**
```
BrushHighlight 템플릿으로 "[예: 저장해두면 / 평생 써먹는 문장]" 만들어줘.
두 번째 줄에 형광펜 밑줄, 옆에 연필 체크, 뒤에 수채화 얼룩.
```

> 🚨 **한 영상에 효과는 1~2개만!** 글리치+수채화+물리 다 섞으면 오히려 싸 보여요.

## 🔁 STEP 5. 피드백 → 기억시키기

결과물이 마음에 안 들면 **구체적으로** 말하고, 마지막에 이 한 줄을 붙이세요.

```
[예: 등장이 너무 느려. 반으로 줄이고, 강조 박스 대신 밑줄로 바꿔줘.]
이번 수정 중 앞으로도 적용할 건 motion-style.md '배운 것' 에 적어둬.
```

이렇게 5~10번만 반복하면 `배운 것` 목록이 쌓여서, **처음부터 내 스타일로** 나오기 시작해요.

### 피드백 잘 주는 표현

| 이렇게 말하지 말고 | 이렇게 말하기 |
| --- | --- |
| "좀 더 세련되게" | "글자 굵기 한 단계 낮추고, 움직임 거리를 절반으로" |
| "빠르게" | "전체 속도 1.5배, 장면당 2초 → 1.5초" |
| "이상해" | "2초쯤에 두 번째 줄이 첫 줄이랑 겹쳐" |
| "임팩트 있게" | "강조 단어만 1.1배 커졌다가 돌아오게" |

> 💡 시간 위치를 말할 땐 Remotion Studio 아래 **프레임 숫자**를 알려주면 가장 정확해요. (30프레임 = 1초)
