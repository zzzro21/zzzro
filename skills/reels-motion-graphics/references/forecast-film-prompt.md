# 정치·경제 전망치 그래프 영상 — 프롬프트 템플릿

원본: "$3,000 견적 받은 런칭 영상을 Opus 5.5(medium)가 한 번에" 사례의 프롬프트 (HyperFrames + GSAP).
이 스킬(Remotion)에 맞게 바꾸고, **전망치 데이터에 꼭 필요한 규칙**을 더했다.
템플릿: `templates/ForecastChart.tsx` · 효과음 `tools/synth_sfx.py` · BGM `tools/synth_bgm.py`

## 원본에서 그대로 가져온 좋은 점

- 길이·도구·금지사항을 첫 줄에 못박기 ("15초, 내레이션 없음, 실사 없음")
- 종이 캔버스 + 그려지는 마커 메모 + 큰 키네틱 타이포 + **명암 전환** + 1.5~2초마다 새 정보 + **치는 순간마다 소리**
- "화면 장식(스크러버·타임코드·fps) 금지, 애니메이터 용어(squash, stagger…) 화면에 쓰지 않기"
- "**지어낸 결과 금지**: %, 배수, 고객명, 수치를 만들지 말 것"
- 모든 시작 상태를 0프레임에 고정(seek-safe), 퇴장을 가리지 않기, 전환마다 주된 움직임 하나
- 음악 구간 설계(명암 전환 때 드럼 드롭, 타이포·로고에 다시 쾅), 효과음 출처 기록
- 마스터링: **-14 LUFS, -2 dBTP, AAC 인코딩 후 다시 측정**

## 전망치 영상에 추가하는 규칙 (반드시)

1. **숫자는 사용자가 준 공식 자료만.** 기관명·발표 시점을 화면에 표기 (예: "기관 A · 2026.10 전망").
2. **실적 = 실선, 전망 = 점선 + 범위 띠.** 확정치와 전망치를 색이 아닌 모양으로 구분.
3. 화면에 **"○○년 ○월 기준"** 과 단위를 항상 표시. 출처 각주는 마지막 2초 이상 남긴다.
4. **정치 관련은 기관 2곳 이상 나란히**, 해석 문구는 중립(원인 단정·특정 정당 평가 금지). 발언 인용은 원문 그대로 + 날짜.
5. 반올림 규칙을 원자료와 같게(소수 첫째 자리 등). 축은 0부터 시작하거나, 아니면 물결 표시로 잘린 축임을 표시.
6. 데이터가 없으면 `example: true` → '예시 데이터' 도장. 예시를 실제처럼 보이게 하지 않는다.

## 복붙 프롬프트 (빈칸 {{ }} 채우기)

```
reels-motion-graphics 스킬로 {{채널: 유튜브 롱폼 / 쇼츠 / 인스타}}용 {{15}}초 모션그래픽 만들어줘.
ForecastChart 템플릿 기반, 내레이션 없음, 실사 없음.

주제: {{예: 2027년 경제성장률 전망}}
데이터 (이 숫자만 쓰고 지어내지 마):
- 실적: {{연도: 값, ...}} (출처: {{통계청 등}})
- 전망 1: {{기관}} {{발표 연월}} — {{연도: 값}} (범위가 있으면 {{하한~상한}})
- 전망 2: {{기관}} {{발표 연월}} — {{연도: 값}}
기준 시점: {{2026년 10월 기준}} / 단위: {{%}}
한 줄 메모(손글씨): {{예: 반등은 하지만 2%대 초반}} ← 데이터가 말하는 것만

스타일: 종이색 캔버스, 마커 메모가 그려지듯 등장, 큰 키네틱 타이포, 
1.5~2초마다 새 정보, 명암 전환 1번(핵심 숫자 공개 순간), 치는 순간마다 효과음.
규칙: 화면 장식·애니메이터 용어 금지, 실적은 실선·전망은 점선+범위,
기관·발표 시점·기준일·출처 각주 필수, 정치적 해석은 중립.
BGM과 효과음은 synth 도구로 합성. 마스터는 -14 LUFS / -2 dBTP, 인코딩 후 다시 측정해서 알려줘.
```

## 마스터링 명령 (테스트됨)

```bash
# 측정
ffmpeg -i out.mp4 -af ebur128=peak=true -f null - 2>&1 | grep -E "I:|Peak:" | tail -2
# 맞추기 (영상은 그대로 복사, 오디오만 AAC 재인코딩) → 다시 측정
ffmpeg -i out.mp4 -c:v copy -af loudnorm=I=-14:TP=-2:LRA=11 -c:a aac -b:a 192k out_master.mp4
```
효과음 위주의 짧은 영상은 피크(-2 dBTP) 한도 때문에 -14 까지 못 올라갈 수 있다 (테스트: -21.1 → -15.9 LUFS, 피크 -2.0).
이때는 피크 한도를 지키는 게 맞고, 결과 수치를 그대로 보고한다.
