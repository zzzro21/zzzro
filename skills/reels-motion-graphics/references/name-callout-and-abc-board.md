## 1. 이름이 나오면 누끼 인물이 자막 위로 (화면녹화 20261023, 12초 쇼츠)

국회 발언 쇼츠. 발언자가 "헨리 조지와 / 시진핑의 공산주의와 … 마찬가지 사례인데요" 라고 말하는 동안:

| 시점 | 화면 |
| --- | --- |
| "헨리 조지" 말하는 순간 | 헨리 조지 **흑백 누끼(가슴 위)** 가 **왼쪽 화면 밖에서** 미끄러져 들어와 자막 바로 위 왼쪽에 자리 잡음. 약 0.15~0.2초, 빠른 감속 |
| "시진핑" 말하는 순간 | 시진핑 흑백 누끼가 **오른쪽 밖에서** 들어와 오른쪽에 |
| 둘이 함께 | 문장이 끝날 때까지 둘 다 그대로. 누끼 아랫단은 자막 뒤로 들어가 잘림(자막이 위) |
| 문장 끝 | 둘이 **같이** 흐려지며 사라짐 (약 0.25초, 블러+페이드) |

- 누끼는 테두리·그림자 없음, **흑백**이라 컬러 원본 영상과 바로 구분된다.
- 이름은 자막에서 따로 색을 주지 않았지만, 쇼치는 이름을 파란색으로 강조해 왔다.
- 같은 영상의 다른 장치: 핵심 단어 장면은 흑백 도시 사진 + 빨간 붓글씨 큰 글자("토지 공산주의").

**우리 구현:** `작업실/영상/_시안/이름누끼_ABC/name_cutout_sian.py` (PIL+ffmpeg, 1080×1920)
- 등장 A 옆에서 밀려 들어옴(레퍼런스) / B 흰 테두리 스티커 뽁 / C 자막 윗선(노랑 선) 아래에서 솟음
- 색 A 흑백 / B 컬러, 이름표 A 없음 / B 가슴 높이 한 줄("정성호 전 장관")
- 자리: 아랫단이 자막 첫 줄 윗선 뒤로 70px 들어감, 오른쪽 150px(쇼츠 UI)은 비움. 누끼 높이 400.
- 이름 시점은 srt 줄 시작 + 앞 말 길이로 잡고, 효과음은 **착지 순간**(등장 0.22초 뒤)에.
- 처음엔 이름표를 얼굴 바로 아래(두 줄)에 두었더니 턱을 가렸다 → 한 줄로 줄여 가슴 높이로.

## 2. A/B/C 고르기 페이지 (화면녹화 20261106, toopeace "클로드 영상편집 수정 7번 → 1번")

사용자가 이 영상을 보고 "영상 만들기 전에 폰트·효과·모션그래픽을 ABC 중에서 고르게 스토리보드부터" 규칙을 만들었다.

페이지 구성 (localhost 의 "릴스 스토리보드 · 클로드 영상편집"):
1. **장면 표**: # · 시간(0:00.0–0:03.8) · 화면 썸네일 · 대사 · 레이아웃(얼굴 전체 / 화면+오른쪽 아래 얼굴) · 모션그래픽.
2. **항목별 카드 줄**: "자막 폰트"(A~E), "모션그래픽 스타일"(A~D: 클로드 크림·다크 모드·딥그린·화이트 미니멀), "화면 장면에서 내 얼굴"(누끼 오른쪽 하단·사각 화면·둥근 카드·위아래 분할)… 카드마다 **같은 실제 장면을 그 옵션으로 렌더한 사진** + 한 줄 설명, 추천 표시.
3. **아래 고정 띠**: "선택: 1A 2C 3B 4A 5A …" + 복사 버튼 → 클로드에게 붙여 넣으면 그대로 만듦 → "수정할 부분이 있으면 장면 번호로 알려 주세요".

**우리 구현:** 같은 형식을 아티팩트 페이지로 (`이름누끼_ABC/board/index.html`) — 항목 번호 + A/B/C 카드(움직이는 시안은 영상, 나머지는 같은 장면 사진), 아래 선택 띠·복사. 소리는 고른 카드 하나만.
