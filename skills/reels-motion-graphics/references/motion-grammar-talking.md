# 토킹 릴스 모션 문법 (레퍼런스 측정)

출처: 사용자가 보낸 한국 크리에이터 인스타 릴스 화면 녹화 (36.7초, AI 숏드라마 제작법 소개).
방법: `analyze_reference.py` + 위젯 구간을 초당 10프레임으로 잘라 한 장씩 비교.
구현: `templates/InfoWidgets.tsx` (v2), `templates/TalkingOverlay.tsx` (`captionMode: "phrase"`, `captionStyle: "pinkpop"`).

## 1. 큰 규칙

| # | 규칙 | 측정 |
| --- | --- | --- |
| 1 | **위젯은 한 아이디어 동안 떠 있다.** 자막은 바뀌어도 위젯은 유지 | 위젯당 3~8초, 그 사이 자막 4~6번 교체 |
| 2 | **전 → 후 두 단계.** 등장은 가는 흰 선이 그려지듯(전), 핵심어가 나오는 순간 분홍으로 채워짐(후) | 선 그리기 약 0.7초, 채움 0.2~0.3초 |
| 3 | **상태 변화 = 핵심어 순간.** 자막의 분홍 핵심어와 위젯 활성화가 같은 프레임 | "프롬프트 영상이" → 노드 채움, "연결하면 돼요" → 체크, "65%" → 카운트 시작 |
| 4 | 위젯은 자막 바로 아래 줄. **좌·중·우에 동시에** 놓일 수 있다 | "3일" 배지(왼쪽)가 떠 있는 채로 65% 링(오른쪽) 추가 |
| 5 | 활성화 순간 **링 펄스 + 방사형 빗금/반짝이** 한 번 | 0.3~0.5초 |
| 6 | 퇴장 = **블러 + 페이드** | 약 0.15초 |
| 7 | 자막: 구절 통째로 흰 글자, 핵심어만 압축 글꼴 분홍 + 흰 테두리 + 빛 번짐 | 자막 교체 0.8~1.5초 간격 |

## 2. 위젯별 동작

| 위젯 | 전 (등장) | 후 (핵심어) |
| --- | --- | --- |
| growth 상승 그래프 | 분홍 선이 왼쪽 아래→오른쪽 위로 그려지고 끝에 흰 점, 꺾이는 곳마다 ₩ 동전이 튀어나옴 | 태그 알약("조회수 · 성장세 ↑") + 끝점에 방사형 빗금 |
| pipeline 단계 | 흰 원과 아이콘 선이 하나씩 그려짐, 사이는 흰 점선 | 분홍 알약 테두리 + 노드가 왼쪽부터 분홍으로 채워지고 실선이 이어짐, 노드마다 링 펄스 |
| connect A ✓ B | 왼쪽 이름이 닦이듯 나타나고 → 오른쪽 이름 → 점선이 이어짐 | 가운데 분홍 체크가 튀어나오며 방사형 빗금 |
| chat | 분홍 알약에 요청 문장이 타이핑 | 흰 답 말풍선이 튀어나옴 ("장면별 프롬프트 완성!") |
| stopwatch | 흰 테두리 원이 그려지고 눈금 | 바늘이 빨라지며 분홍 부채꼴, 옆에 스피드 선 |
| calendar | 살짝 회전하며 툭 튀어나옴 | (그대로 유지, 다른 위젯과 나란히) |
| ring 퍼센트 | 어두운 원 + 0% | 0→목표 **ease-in-out 약 1초** (측정: 0, 2, 6, 14, 27, 43, 54, 61, 64, 65) → 끝에 반짝 |
| comment 댓글 | 입력창 테두리가 왼→오로 그려지고 "댓글 달기..." | "댓글 남겨주시면"에 맞춰 키워드가 한 글자씩 → 전송 버튼 분홍 + 링 → 종이비행기 날아감 → 하트가 떠오름 |
| timer 길이 막대 (템플릿에 아직 없음) | 파이프라인 아래에 시계 아이콘 + 가는 흰 막대가 왼→오로 차며 오른쪽 숫자 "3초→5초" | "30초짜리"에 맞춰 막대가 분홍으로 끝까지 차고 숫자가 분홍 "30초"로 바뀌며 반짝이 (약 2초, 13.5초~20초 구간) |

## 3. 쓰는 법

```json
{ "type": "pipeline", "at": 2.6, "dur": 4.0, "activateAt": 5.0, "steps": [...] }
{ "type": "ring", "at": 9.0, "dur": 4.0, "activateAt": 10.2, "from": 0, "to": 65, "x": 0.72 }
{ "type": "calendar", "at": 8.0, "dur": 5.0, "big": "3일", "label": "무제한 무료", "x": 0.22 }
{ "type": "comment", "at": 13.0, "dur": 4.4, "typeAt": 14.2, "keyword": "모션" }
```
- `at` = 위젯 등장(전), `activateAt` = 자막 핵심어 시각(후), `dur` = 아이디어 전체 길이.
- 숫자 위젯은 실제 수치만.
