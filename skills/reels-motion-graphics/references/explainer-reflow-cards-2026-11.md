# 설명 영상의 카드 재배치 · 그래프 이동 — 레퍼런스 (2026-11-28)

> 사용자가 보낸 한국어 유튜브 설명 영상(조회수 하락 이유, 14분 32초, 2560×1440, 영상 ID uk08e42hVLA). 영상 파일은 저장소에 올리지 않는다.
> 사용자가 짚은 점: **"모션그래픽의 사이즈 변경과 위치 변경의 유연함, 그래프 이동"**.
> 방법: 4초 간격 장면표 8장 + 전환 구간을 초당 2.5~10프레임으로 잘라 비교.

## 1. 화면 바탕 (전 장면 공통)

| 요소 | 값 |
| --- | --- |
| 바탕 | 크림색 종이(#EFECE6 근처) + 가장자리 아주 옅은 비네트. 네 귀퉁이에 **주황 L자 재단선** |
| 강조색 | 주황빨강 **#E0592D** 하나. 그 외는 진회색 글자(#3D3D3A)·흰 카드 |
| 카드 | 흰 둥근 사각형, 얇은 회색 테두리 + 아주 옅은 그림자. 강조 카드는 **왼쪽 주황 세로줄** 또는 주황 테두리 |
| 제목 | 가운데 위. 위에 **작은 영문 대문자 꼬리표**(STUDIO CHECKLIST, IMPRESSIONS, VIDEO-CENTRIC…)를 주황으로 아주 작게, 그 아래 굵은 한글 제목, 핵심어만 주황 |
| 자막 | 아래 가운데 검은 반투명 띠 + 흰 글자 (편집 자막과 별개) |
| 장 구분 | 4칸 체크리스트(01 노출수·02 클릭률…) → 사라지고 **왼쪽 위에 큰 번호 원 + 장 제목**, 오른쪽 위에 **작은 목차 알약 4개**(지금 장만 주황 채움). 장이 바뀌면 그 알약만 옮겨 칠해짐 |
| 인터뷰 원본 | 원 영상 화면은 통째로 넣고 아래 자막만. 기사·문서 화면은 노란 형광 문단을 확대해 천천히 위로 |

## 2. 크기·위치를 바꾸는 방식 — "재배치(reflow)"

핵심: **장면을 바꾸지 않고, 새 요소가 들어올 자리를 기존 요소가 비켜 준다.** 한 화면이 문장마다 조금씩 다시 짜인다.

| 상황 | 움직임 | 측정 |
| --- | --- | --- |
| 오른쪽에 설명 카드가 들어올 때 | 가운데 있던 화면 캡처(그래프) 카드가 **왼쪽으로 이동 + 약 85~90%로 작아짐**, 빈 오른쪽에 카드가 아래→위로 살짝 떠오르며 등장 | 이동·축소 약 0.4~0.5초, 감속(ease-out). 두 동작이 같은 곡선으로 동시에 |
| 아래에 꼬리표가 붙을 때 | 위 카드가 **위로 20~30px 밀려 올라가고**, 생긴 자리에 알약 꼬리표("이전 영상과 비교")가 나타남 | 약 0.3초 |
| 목록이 늘어날 때 | 기존 줄들이 위로 한 칸 올라가 **전체가 다시 가운데 정렬**, 새 줄이 맨 아래에 | 줄 하나 = 문장 하나 |
| 한 요소를 버릴 때 | 틀린 말 카드는 **가로 취소선**이 그어지고 흐려짐("모든 영상의 추천 횟수 기준"), 지난 화면 전체는 흐려지며 다음 요소만 남음 | 취소선 0.3초 |
| 장면 끝 | 하나씩 빠지지 않고 **전체가 흐려지며(블러+페이드)** 다음 장면 | 약 0.3초 |

- 위치는 항상 **화면 전체 무게중심이 가운데에 오도록** 다시 계산된다. 하나만 있으면 가운데, 둘이면 좌우, 셋이면 왼쪽 큰 것 + 오른쪽 둘 위아래.
- 같은 요소는 장면 내내 **같은 물체**로 남는다(사라졌다 다시 생기지 않는다). 그래서 눈이 따라가기 쉽다.

## 3. 그래프·화면 캡처 다루기

| 단계 | 동작 |
| --- | --- |
| 1 등장 | 스튜디오 캡처를 그대로 쓰지 않고 **흰 카드 위에 다시 그린 그래프**(보라 선, 회색 축). 카드 위 작은 꼬리표 "MY CHANNEL · 조회수" |
| 2 숫자 짚기 | 말에 숫자가 나오는 순간 그 숫자(28.8만, 150.4만, 5.4%) 둘레에 **주황 얇은 사각 테두리**가 그려짐(약 0.2초), 장면 끝까지 남음 |
| 3 구간 짚기 | "급격히 올랐다가 떨어지고" → 튀어 오른 봉우리마다 **옅은 주황 채움 + 주황 테두리 세로 상자**. 하나 뒤 또 하나(약 0.3초 간격) |
| 4 줄 짚기 | 유입 경로 표에서는 해당 줄(탐색 기능 90.9%) 전체에 주황 테두리 |
| 5 옆으로 비키기 | 해석이 붙을 때 그래프 카드가 왼쪽으로 가며 작아지고(2장), 오른쪽에 해석 카드 2~3개가 쌓임. 마지막 결론 카드만 주황 테두리 |
| 6 선 그리기 | 단순 꺾은선은 왼→오로 그려지고 끝점에 **주황 점**이 툭(예: "시간이 지나 다시 오르는 영상") |

## 4. 그 밖의 장치

- **숫자 크게**: "19번" 같은 핵심 숫자는 화면 가운데 아주 크게 주황, 아래 작은 회색 설명. 다음 문장에서 설명 줄에 취소선.
- **≠ 비교 카드**: "화면에 나타남 ≠ 사람의 눈에 들어옴" — 두 카드 사이 주황 ≠, 오른쪽 카드만 주황 테두리.
- **휴대폰 세 대**: "같은 시간, 다른 홈 화면" — 세 휴대폰 화면 칸 색이 서로 다르게.
- **벤 다이어그램**: 두 원(회색·주황)이 다가가 겹치고 겹친 곳에 주황 알약("채널의 접점").
- **흐름 화살표**: "숫자 확인 → 개선점 한 가지 → 다음 영상에 적용"을 한 줄로, 가운데만 주황 알약.
- 체크·X 아이콘이 달린 결론 줄(✓ 주황 / ⊗ 회색).

## 5. 우리 채널에 쓰는 법

- **내일의 여행자(경제+언어, 16:9 롱폼)에 가장 맞다.** 종이 바탕 + 흰 카드 + 강조색 하나 구성이 "종이 질감 푸른빛 흰색 바탕·글자 남색" 지침과 같은 방향 → 크림 대신 **푸른빛 흰 종이**, 주황 대신 **남색(또는 남색+주황 꼬리표)** 으로 바꿔 쓴다. 어두운 바탕 금지 지침과도 맞는다.
- 쇼치 롱폼에서는 사람 영상 위주라 이 화면은 **데이터·정리 장면에만**(스튜디오 숫자, 판결 비교, 연표).
- 구현 방향(아직 템플릿 없음): Remotion에서 요소마다 `slot` 목록(문장 시각별 x·y·scale)을 주고, 바뀔 때마다 `spring`/`interpolate`(0.45초 ease-out)로 옮긴다 = FLIP 방식. 그래프는 SVG로 다시 그리고 `highlight: [{at, kind: "value"|"range"|"row", target}]`로 주황 테두리를 그린다. 시안은 A/B/C 고르기 페이지로 먼저 보여 준다.
