# 효과 이름 사전 — 레퍼런스 릴스 2편 분석 (2026-11-27)

> 사용자가 보낸 인스타 화면 녹화 2편. 둘 다 "효과 목록을 차례로 시연하는" 형식이라 **효과 이름 사전**으로 쓴다.
> 스토리보드에서 폰트·효과·모션을 A/B/C 로 제안할 때 이 이름으로 부른다 (SKILL.md 3단계).

## 1. orr.design — "글자가 움직이는 효과에도 이름이 있어요" (텍스트 애니메이션 12가지, 29초)

**형식:** 연보라 단색 배경, 위 제목 2줄 고정(핵심어 '이름' 보라), 왼쪽에 12개 목차(현재 항목 보라 굵게), 가운데 카드 1장에서 "Hello, World" 로 시연, 카드 아래 번호·한글 이름·영문 이름. 첫 2초는 12개 격자 한꺼번에 → 그다음 하나씩 약 2초씩. 끝에 다시 처음으로 루프. 음악 BPM 약 176, 컷 없음(한 화면 안에서 카드만 바뀜).

| # | 이름 (영문) | 움직임 | 우리 쓰임 |
| --- | --- | --- | --- |
| 1 | 타자기 (Typewriter) | 한 글자씩 + 깜빡이는 커서 | 기사·문자 인용, 개인 릴스 자막(이미 규칙) |
| 2 | 스태거 텍스트 (Staggered) | 글자마다 시차 두고 아래서 솟음 | 롱폼 핵심 문구 (5편 A+C 와 같은 계열) |
| 3 | 마스크 리빌 (Text mask reveal) | 선 아래 가려진 데서 올라옴 | 다큐 마스크 = 쇼치 A안 |
| 4 | 블러 인 (Blur in) | 흐림→선명 | 차분한 롱폼·내일의 여행자 |
| 5 | 스크램블 (Scramble) | 무작위 기호가 글자로 정착 | 폭로·"숨겨진 사실" 순간 |
| 6 | 단어 로테이터 (Word rotator) | 한 단어만 위아래로 바뀜 (Make it fast→bold) | 훅 "○○은 ___다" |
| 7 | 스플릿 플랩 (Split-flap) | 공항 출발판처럼 칸마다 넘어감 | 날짜·숫자 공개 (※ 딸깍 소리 = 금속성, 쇼치 금지) |
| 8 | 숫자 카운트업 (Number ticker) | 0→11,473 | 세금·예산 숫자 (월급 환산과 같이) |
| 9 | 샤이니 (Shiny) | 빛 띠가 글자를 훑음 | 썸네일 문구 등장, 고급스러운 강조 |
| 10 | 형광펜 하이라이트 (Marker highlight) | 글자 밑에 노랑 칠이 그어짐 | 조문·인용 카드(이미 규칙) |
| 11 | 글리치 (Glitch) | 색 어긋남·찢김 | 거짓말·조작 지적, 짧게만 |
| 12 | 텍스트 마키 (Marquee) | 두 줄이 반대 방향으로 흐름 | 쇼츠 위 띠·엔딩 배경 |

**배운 점:** 효과를 **이름 + 같은 문장("Hello, World")** 으로 나란히 보여 주면 고르기 쉽다 → A/B/C 시안도 같은 문장 하나로 세 효과를 보여 준다.

## 2. justyn.ai — "20 video effects in 20 seconds, built by Claude" (28초)

**형식:** 말하는 사람 촬영본(9:16)이 주인공. 왼쪽 위 짙은 초록 반투명 목록 "IN THIS VIDEO 06 / 20" 이 계속 떠 있고, 지금 효과가 흰 알약으로 표시됨 → 보는 사람이 진행도를 앎. 효과 하나 약 1초, 말과 동시에. 위 흰 박스 3줄 제목("20 video effects / in 20 seconds, / built by Claude"). CTA: 댓글 "EDIT" → 댓글창 그려지고 EDIT 입력 → 하단 말풍선 "Comment EDIT to get access to these + 40 more effects". 끝은 처음과 같은 장면(루프).

| # | 이름 | 화면 | 우리 쓰임 |
| --- | --- | --- | --- |
| 01 | Running list | 왼쪽 진행 목록 자체 | 롱폼 목차·쇼츠 "3가지" |
| 02 | Live cursor | 사람 주위 선택 박스 + 마우스 커서 + 'Claude' 이름표 | "AI가 고른다" 연출 (내일의 여행자) |
| 03 | Clone row | 같은 사람이 옆으로 여러 명 줄지음 | 반복·"또 같은 말" |
| 04 | Day dial | 사람 뒤 시계 다이얼 회전(day 글자) | 날짜·기한 (1/31 같은) |
| 05 | Predict keys | 아래 자판 + 자동완성 단어 | 검색어·말 예측 |
| 06 | Orbit ring | 머리 주위 고리가 돎 | 인물 소개 |
| 07 | Code body | 사람이 글자(코드)로 채워짐 | AI·데이터 주제 |
| 08 | Post wall | 위에 잔디 달력·"1,213 posts" 카운트 | 누적 숫자(게시물·회차) |
| 09 | Letter dive | 큰 세리프 글자 "dive" 구멍 속으로 사람이 보임 | 제목 스팅 |
| 10 | Comment drop | 댓글 카드가 떨어짐 | 댓글 반응·CTA |
| 11 | Layer explode | 화면이 3D 판 여러 장으로 분해 | 편집 과정 보여 주기 |
| 12 | Sketch words | 필기체 손글씨가 그려짐 | 개인 릴스 손글씨(이미 규칙) |
| 13 | Blade slice | 화면이 사선으로 잘려 밀림 | 장면 전환 |
| 14 | Head stack | 얼굴 옆에 단어 라벨들이 쌓임 | 인물 별명·혐의 목록 (쇼치) |
| 15 | Rack focus | 초점이 뒤→앞 이동 | 롱폼 장면 전환 |
| 16 | Banknote | 사람이 지폐 도안 속 초상으로(일련번호·17) | 돈·세금 주제 (쇼치·내일의 여행자) |
| 17 | Impact frame | 흑백 만화 선화 + 집중선 + "IMPACT" | 결정적 한마디 (쇼치 쾅 장면) |
| 18 | Dolly zoom | 배경만 늘어나는 현기증 줌 | 충격 반전 |
| 19 | Press front | 신문 1면("The Daily Reel")에 사람·제목 | 보도 인용 — 실제 기사 캡처 규칙과 함께 |
| 20 | Paper tear | 종이 찢어지며 다음 장면 | 전환 |

**배운 점**
1. **진행 목록을 계속 띄우면** 빠른 나열도 덜 어지럽다 ("06 / 20" 숫자 + 현재 항목 흰 알약).
2. 효과는 **사람 촬영본을 바꾸는 것**(누끼·지폐·신문·만화)이 글자만 움직이는 것보다 눈에 걸린다 → 쇼치 "바탕은 사람 영상·사진" 지침과 같은 방향.
3. 질감이 효과마다 다르다: 지폐 동판화 선, 신문 망점, 만화 집중선. 누끼(`tools/person_matte.py`) + 선화/망점 필터로 만들 수 있다.
4. 루프: 마지막 장면 = 첫 장면.
