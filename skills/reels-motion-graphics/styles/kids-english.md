# 어린이 영어 앱 스타일 (학습 게임 · 그림책 장면)

> 렌더: `--props='{"channel":"kids-english"}'` · 수치는 `templates/brand.ts` 의 `kids-english` 프로필
> **이 채널만 색이 다르다**: 개인 브랜드가 아니라 **앱 브랜드 색**(`palette`)을 쓴다. 앱 색이 정해지면 `palette` 만 바꾼다.

## 왜 코드로 만드나 (사용자 사례)
- "Lernok 티저를 Opus 5.5 + HyperFrames 로 **제로샷**. 영상 생성 모델이 아니라 **효과음·음악·애니메이션 전부 코드**, 이미지·영상 에셋 없음 → 인포그래픽을 세밀하게 제어하고 **매번 같은 결과(결정적 출력)**. 내레이션은 OpenAI TTS."
- 교재는 같은 단어·같은 그림이 **매번 똑같이** 나와야 한다 → 생성형 영상보다 코드가 맞다.
- 다른 사례: 원작 프롬프트 그대로 Claude Code + Remotion 공식 플러그인, **effort xhigh**, 프롬프트 1번(중간 API 끊김에 continue 1번), 생각 약 23분 + 렌더 약 90초, BGM 도 코드 생성.
  → 긴 작업은 **끊겨도 "계속" 한 번이면 이어진다.** 처음부터 다시 시키지 않는다.

## 캔버스
- 1920×1080 (태블릿·앱 화면), 30fps. 앱에 세로 화면이 있으면 같은 템플릿을 9:16 으로도 렌더.
- 안전영역 상하 80 · 좌우 100. 아이 손가락으로 누를 영역(퀴즈 카드)은 최소 260px.

## 글자
- 헤드라인 140 · 제목 96 · 본문 72 · 캡션 44. **둥근 글꼴**(Nunito 계열), 굵게.
- 영어 문장은 한 화면 2줄 이내. 단어 사이 간격 넉넉히(하이라이트가 겹치지 않게).

## 리듬
- 장면 2.5–5초, 등장 12프레임 — 어른용보다 **느리게**.
- 단어 하이라이트는 **내레이션 단어 시각**에 맞춘다. TTS 가 단어 시각을 주면 `words[].at` 에, 없으면 글자 수로 자동 배분.
- 에너지: 중간 — 플래시·흔들림·글리치 금지. 대신 **통통 튀기(squash & stretch)**, 반짝, 동그라미.
- BGM 100 BPM, 내레이션 밑에 아주 작게. 효과음은 정답·등장에만 (pop, ding, tick).

## 학습 설계 규칙
1. **단어 ↔ 그림 연결**: 문장에서 단어가 읽히는 순간 그 그림이 반응한다 (cat → 고양이가 통통).
2. **파닉스**: 핵심 단어를 소리 단위로 쪼개 색을 다르게 하나씩 → 합쳐서 한 단어.
3. **확인 퀴즈**: 그림 3개 중 고르기. 오답 그림은 장면에 나왔던 것 + 새 것 섞기. 정답 공개는 2~3초 기다린 뒤.
4. 그림은 **단순한 도형 + 두꺼운 외곽선** (아이가 바로 알아보게). 그림은 코드로 그린 것 또는 앱이 소유한 일러스트만.
5. 문장·단어는 교재 원문 그대로. 철자·문법을 바꾸지 않는다.

## 내레이션 (TTS)
- OpenAI TTS·ElevenLabs 등은 **API 키·커넥터가 연결된 경우에만**. 생성 전에 문장과 비용을 확인받는다.
- 단어 시각이 필요하면 단어 타임스탬프를 주는 TTS 를 쓰거나, 문장을 단어별로 끊어 생성 후 이어붙인다.
- 연결이 없으면 자막 + 효과음만으로 만든다 (`narration` 비움).
