# 개인 인스타 (릴스) 스타일

> 렌더: `--props='{"channel":"instagram"}'` · 수치는 `templates/brand.ts` 의 `instagram` 프로필
> 색·폰트·핸들은 세 채널 공통(`BRAND_CORE`). 여기는 **인스타에서만 다른 점**.

## 목표
- **저장·공유**가 핵심 지표. "나중에 다시 볼 정보" 처럼 보여야 한다.
- 사람(나)이 느껴지는 톤. 차갑고 기계적인 연출보다 **따뜻하고 깔끔하게**.

## 캔버스
- 1080×1920, 30fps, 길이 15–30초
- 안전영역: 위 220 · 아래 420 · 왼쪽 90 · **오른쪽 150** (좋아요·댓글 버튼 열)
- **프로필 그리드 썸네일은 가운데 3:4(1080×1440) 로 잘린다** → 첫 장면 핵심 문구는 세로 240~1680 안에.
- 커버로 쓸 프레임(보통 0.5초 지점)은 글자만 봐도 주제가 보이게.

## 글자
- 헤드라인 112 · 제목 84 · 본문 64 · 캡션 44 (px)
- 한 화면 최대 3줄, 줄당 10자 안팎.

## 리듬
- 장면 1.8–3초, stagger 8프레임, 등장 10프레임
- BGM 기본 110 BPM (차분하게 신나는 정도)
- 에너지: **중간** — 플래시·흔들림은 영상당 1번까지, 글리치는 특별한 경우만.

## 어울리는 템플릿
| 용도 | 템플릿 |
| --- | --- |
| 첫 1초 훅 | KineticHook |
| 저장 유도 엔딩 | BrushHighlight (형광펜·연필 체크) |
| 정보 나열 | PhysicsWords, AnimeTimeline |
| 과정 설명 | SketchDiagram (손그림 → 친근함) |
| 성과 공개 | StatsLaunch (실제 숫자만) |

## 마무리 고정 장치
- 마지막 1초: "저장해두세요" 류 한 줄 + 핸들. 댓글 키워드 이벤트면 키워드를 크게.
