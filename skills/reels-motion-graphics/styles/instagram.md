# 개인 인스타 (릴스) 스타일

> 렌더: `--props='{"channel":"instagram"}'` · 수치는 `templates/brand.ts` 의 `instagram` 프로필
> 색·폰트·핸들은 세 채널 공통(`BRAND_CORE`). 여기는 **인스타에서만 다른 점**.

## 목표
- **저장·공유**가 핵심 지표. "나중에 다시 볼 정보" 처럼 보여야 한다.
- 사람(나)이 느껴지는 톤. 차갑고 기계적인 연출보다 **따뜻하고 깔끔하게**.

## 캔버스
- 1080×1920, 30fps, 길이 15–30초
- 안전영역: 위 220 · 아래 420 · 왼쪽 90 · **오른쪽 150** (좋아요·댓글 버튼 열)
- **프로필 그리드 썸네일은 가운데 3:4(1080×1440) 로 잘린다** → 첫 장면 핵심 문구는 세로 240~1680 안에.
- 커버로 쓸 프레임(보통 0.5초 지점)은 글자만 봐도 주제가 보이게.

## 글자
- 헤드라인 112 · 제목 84 · 본문 64 · 캡션 44 (px)
- 한 화면 최대 3줄, 줄당 10자 안팎.

## 리듬
- 장면 1.8–3초, stagger 8프레임, 등장 10프레임
- BGM 기본 110 BPM (차분하게 신나는 정도)
- 에너지: **중간** — 플래시·흔들림은 영상당 1번까지, 글리치는 특별한 경우만.

## 내 촬영본 위에 얹기 (토킹 릴스) — 기본 방식
인스타는 **내가 나오는 영상이 주인공**이다. 그래픽이 화면을 통째로 덮으면 못 쓴다. (사용자 피드백)
레퍼런스 original_45: 토킹 영상 + 단어 자막 + 검색창 타이핑 + 하트 카운터 + 스티커·도장·말풍선 + 배경 교체 + 사람 뒤로 지나가는 글자.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 자막·스티커·말풍선·카운터만 얹기 | `TalkingOverlay` — 투명 배경으로 렌더(ProRes 4444)해서 캡컷에서 내 영상 위에, 또는 `video` 로 바로 합성 |
| **사람은 그대로, 배경만 교체** | `tools/person_matte.py` 로 누끼 → `CutoutStage` (bg: original · sunburst · speed · popart · dusk · grid) |
| **글자가 사람 뒤로 지나가기** | `CutoutStage` 의 `behindText` (원래 배경에서도 가능) |
| 사람에 흰 스티커 테두리 / 흑백 만화 톤 | `CutoutStage` 의 `outline`, `tone` |

- 얼굴 보호: 자막은 가슴 높이(lower) 또는 사람 옆(left/right). 얼굴 사각형(`face`)에는 그래픽 금지.
- 자막 시간: 캡컷·Vrew 에서 뽑은 자막(SRT) 시간을 `captions` 에 그대로. `*단어*` 는 강조(팝 글꼴·연두).
- 누끼 품질: 단색 벽 앞, 옷과 배경 색이 다를수록 깨끗하다. 흰 책상·흰 옷이 붙어 있으면 그 부분이 사람으로 잡힐 수 있다. 처리 속도는 이 환경 기준 3초 영상에 약 20초.

### 핑크 정보 위젯 스타일 (한국 토킹 릴스) — `captionMode: "phrase"`, `captionStyle: "pinkpop"`
레퍼런스: 사용자가 보낸 인스타 릴스 화면 녹화 (AI 숏드라마 제작법 소개).
- 자막: 말하는 **구절 전체**를 흰 글자로, `*핵심어*` 는 세로로 긴 압축 글꼴(Do Hyeon) + 분홍 + 흰 테두리 + 빛 번짐. 높이 약 56% (턱 아래).
- 자막 바로 아래에 말에 맞춰 **정보 위젯** 하나씩 (`InfoWidgets.tsx`): `growth` 상승 그래프 · `pipeline` 단계 노드 · `connect` A ✓ B · `chat` 요청→완성 · `stopwatch` · `calendar` 날짜 배지 · `ring` 원형 카운터 · **`comment` 댓글창에 키워드 타이핑 → 전송 → 하트** (댓글 키워드로 자료 받는 흐름의 마지막 장면에 딱).
- 밝은 배경·흰 옷이면 자막 뒤 옅은 어두운 띠(`scrim`)가 자동으로 깔린다.
- 숫자 위젯(growth·ring·calendar)은 **실제 수치만**. 없으면 쓰지 않는다.
- 오른쪽 인스타 버튼 열을 피해 위젯 중심은 화면 46% 지점.

## 팝 티저 (PopTeaser)
- 형식: 9:16, 10~15초, **약 1.5초(3박)마다 컷**, 컷마다 배경색 + 무늬(망점·사선) 교체.
- 글자: 굵은 한글 팝 글꼴(Black Han Sans) + **흰 글자·두꺼운 남색 외곽선·아래로 떨어지는 그림자**, 핵심어만 노랑/핑크/민트. 한 글자씩 튀어나옴. 한 줄이 넘치면 자동 축소.
- 장치: 기울어진 본편 썸네일 카드(흰 테두리+그림자), 그래프 아이콘 타일, 원 링, 반짝이, 사선 와이프 전환, 진행 점.
- 마지막 컷은 길게(6박): "방법은 ○○로 / 프로필 링크 / 댓글 키워드" 유도.
- 캐릭터: 원본처럼 왼쪽 아래 포즈가 컷마다 바뀌면 훨씬 살아난다. **직접 만든(소유한) 캐릭터 이미지만** `scenes[].pose` 로. 없으면 글자를 키워 가운데 배치(자동).
- 장면은 `scenes` 배열만 바꾸면 새 예고편.

## 캐릭터 숏폼 (사용자 사례)
- 사례: Opus 5.5 + Remotion, 캐릭터 일러스트는 **직접 만들어 둔 이미지**(Midjourney), ElevenLabs 연결 → 클로드가 "나레이션 만들게요", "효과음도 만들어도 될까요?" 하며 **나레이션·효과음을 스스로 생성**.
- 인스타에서는 이 방식을 기본 포맷 중 하나로 쓴다:
  - 캐릭터는 **사용자 소유 이미지만** (`public/character/*.png`). 남의 캐릭터·유명 IP 금지.
  - 캐릭터 움직임: 통통 튀는 등장(spring), 말할 때 살짝 위아래(2~3px, 음절마다), 눈 깜빡임은 이미지 2장 교체.
  - 대사는 자막으로 크게, 캐릭터 말투(어미)를 `motion-style.md` 에 적어두고 유지.
  - **음성/효과음 API(ElevenLabs 등)는 커넥터·API 키가 연결된 경우에만** 쓴다. 생성 전에 대본과 비용을 한 번 확인받고, 연결이 없으면 `synth_sfx.py` 효과음 + 자막만으로 만든다.
  - 나레이션 파일을 받으면 `analyze_reference.py` 로 문장 시작 시각을 잡아 자막·컷을 맞춘다.
