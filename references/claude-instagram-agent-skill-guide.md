## ⚡ 진짜 쓸 만한 5개

### ✍️ 1. 대본 — `/ig-reel`

주제만 주면 **후킹 공식 26개** 중에서 첫 문장 3개를 골라 점수를 매기고, 대본·자막·구성까지 짜줘요.

```
/ig-reel 주제: 퇴근 후 30분으로 인스타 키운 방법
```

💡 실제 있었던 일이나 숫자를 같이 적으면 훨씬 좋아져요.

---

### 💬 2. 댓글 답글 — `/ig-reply`

댓글을 붙여넣으면 중요한 댓글부터 **답글을 알아서 써줘요.** 복사해서 달기만 하면 끝.

```
/ig-reply 아래 댓글에 답글 써줘.
[댓글 붙여넣기 또는 캡처 첨부]
```

💡 같은 질문이 여러 개면 "이건 릴스로 만드세요"라고 알려줘요. 다음 콘텐츠 소재가 생기는 거예요.

---

### 🔍 3. 프로필 점검 — `/ig-profile`

프로필 화면을 캡처해서 올리면 **100점 만점**으로 채점하고, 지금 당장 고칠 것부터 다시 써줘요.

```
/ig-profile 첨부한 내 프로필 보고 점수 매기고 고쳐줘.
```

💡 프로필 윗부분 + 게시물 두 줄까지 보이게 캡처하세요.

---

### 📅 4. 일주일 계획 — `/ig-plan`

이번 주에 **뭘, 언제, 어떻게** 올릴지 정리해줘요.

```
/ig-plan 이번 주 계획 짜줘.
- 내 계정 주제:
- 이번 주 있었던 일:
```

💡 매주 월요일에 한 번만 돌리면 돼요.

---

### 🔥 5. 떡상 영상 분석 — `/ig-viral`

제일 미친 기능이에요.

그냥 조회수 높은 영상이 아니라, **그 계정 평소보다 몇 배 터진 영상**을 찾아줘요. 왜 터졌는지 분석하고 **내 대본으로** 바꿔줘요.

```
/ig-viral 내 분야는 [내 분야]야.
참고할 계정은 @계정1, @계정2, @계정3 이야.
제일 잘 터진 릴스 분석하고, 내 대본으로 하나 써줘.
```

💡 나랑 비슷한 분야 계정 6~12개 정도 알려주면 돼요.
💡 클로드가 인스타 화면을 봐야 해서, 크롬에 **Claude in Chrome**을 연결하고 쓰세요. 어렵다면 영상 첫 문장이랑 조회수를 직접 붙여넣어도 돼요.
