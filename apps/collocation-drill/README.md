# 콜로케이션 1000 드릴

TIER ONE English 「최빈도 콜로케이션 1000 + 구동사 100」 단어장으로 만든 반복 학습 웹앱입니다.

- **빈칸 채우기** Lv1 보기 고르기 → Lv2 첫 글자 힌트로 직접 쓰기 → Lv3 듣고 문장 전체 받아쓰기(WFD)
- **따라 말하기** Lv1 표현만 3번 따라 하기 → Lv2 예문 보며 읽기(RA) → Lv3 듣고 따라 말하기(RS)
  - 음성 인식이 되는 브라우저(Chrome)에서는 말한 문장을 채점하고, 안 되면 스스로 평가합니다.
- **반복 학습** 틀린 표현은 세션 안에서 다시 나오고, 라이트너 상자(간격 반복)로 복습함에 모입니다. DAY를 끝낼 때마다 1·2·3회독이 체크됩니다.
- **내 문장 노트** 매일 외우고 싶은 문장을 날짜별로 적어 두고(한 줄에 한 문장, `영어 | 뜻`), 오늘 · 최근 7일 · 전체 랜덤 범위로 연습합니다.
  - 듣고 따라 말하기: Lv1 보며 따라 말하기 → Lv2 한국어 뜻만 보고 말하기 → Lv3 글자 없이 듣고 따라 말하기
  - 랜덤 빈칸 채우기: 할 때마다 문장 속 단어가 무작위로 빈칸이 됩니다 (Lv1 보기 고르기, Lv2 1–2단어 직접 쓰기, Lv3 받아쓰기)
  - claude.ai 아티팩트에서는 노트가 내 계정의 비공개 저장소에, 로컬에서는 브라우저에 저장됩니다.
- 교재 진행 기록은 브라우저(localStorage)에 저장됩니다.

## 실행
`data.json`을 fetch로 읽기 때문에 웹 서버로 열어야 합니다.

```bash
cd apps/collocation-drill && python3 -m http.server 8000
# http://localhost:8000
```

## 데이터
`data.json` 한 줄 = `[구분(c=콜로케이션, p=구동사), DAY, 번호, 표현, 발음기호, 뜻, 예문, 기출 유형, 빈칸 시작, 빈칸 끝]`.
PDF에서 잘려 있던 예문 32개는 끝 단어를 보완했습니다.
